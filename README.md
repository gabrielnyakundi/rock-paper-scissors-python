

# Rock Paper Scissors Game

A desktop Rock Paper Scissors game built with Python and Tkinter. Play against the computer, track scores, and enjoy a simple interactive gaming experience.

## Features
- Interactive graphical interface (GUI)
- Play against the computer
- 5 rounds per game
- Score tracking for both player and computer
- Countdown before each round
- Play Again option
- Restartable gameplay

## Technologies Used
- Python
- Tkinter
- Git
- GitHub

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/gabrielnyakundi/rock-paper-scissors-python.git
   ```
2. Open the project folder.
3. Run the game:
   ```bash
   python rock_paper_scissorsgui.py
   ```
